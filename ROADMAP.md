# Roadmap de integración — sin alterar los originales

## Disponible en este prototipo

- [x] Estructura Jekyll, navegación, diseño responsive, páginas y fichas por colección.
- [x] Enlaces de retorno a Google Sites para recursos todavía no migrados.
- [x] 3 notebooks demostrativos sintéticos; exportación reproducible a HTML.
- [x] 1 Geo App operativa usando JavaScript, sin back-end.
- [x] GitHub Actions para publicar el sitio después de crear el repositorio.
- [x] Documentación de arquitectura y fuentes/licencias.

## Pendientes antes de un sitio público definitivo

- [ ] Revisar cada biografía, institución, título, servicio y afiliación antes de su publicación.
- [ ] Crear el repositorio GitHub Pages, definir el dominio y probar la publicación.
- [ ] Vincular notebooks de investigación reales **solo si se dispone de sus fuentes y permisos**; no modificar los existentes.
- [ ] Decidir qué repositorios permanecerán privados por propiedad intelectual o datos sensibles.
- [ ] Importar fotografías originales con créditos y derechos claros.
- [ ] Convertir presentaciones/PDFs en fichas con citas y links autorizados.
- [ ] Revisar si la 1D consolidation app puede ser migrada a código fuente independiente.
- [ ] Activar enlaces a Colab cuando el repositorio público ya exista.
- [ ] Añadir pruebas automatizadas de fórmulas, unidades y consistencia cuando haya notebooks reales.
- [ ] Desarrollar versiones ES / PT si se desea.
- [ ] Incorporar JupyterLite solo si hay una necesidad de ejecución totalmente local en el navegador y librerías compatibles.
- [ ] Completar material de Knowledge con bibliografía primaria y notas de validación.

## Límites intencionales

- Este proyecto no reproduce resultados de simulaciones PLAXIS ni garantiza capacidad de carga de anclas.
- No hay datos de campo, resultados inéditos ni publicación automática de trabajos profesionales.
- No se hicieron cambios en Google Sites, el GitHub público ni el ZIP de referencia.
