## Scope

Seismic hazard assessment and local site response studies form part of the existing professional portfolio. The publication architecture can host a technical workflow using source catalogs, coordinate transformations, catalog cleaning, plots and quality-control reports.

### Proposed notebook structure

- Data origin and catalog completeness.
- Magnitude scales, duplicate detection, temporal/spatial visualizations.
- Event filtering and uncertainty disclosure.
- Hazard computation and site amplification only with the governing methods, inputs and validation recorded.
